=======================================
Follow Us Clothing - E-Commerce Website
=======================================

Ini adalah repositori untuk website toko pakaian online **Follow Us Clothing**. Aplikasi ini dibangun menggunakan framework PHP CodeIgniter dan Bootstrap.

Fitur
-----
* Halaman beranda untuk melihat produk terbaru dan koleksi.
* Fitur pencarian barang dan Filtering.
* Halaman Admin Dashboard untuk mengelola produk.

Teknologi yang Digunakan
------------------------
* **Backend:** PHP (Framework CodeIgniter 3)
* **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
* **Database:** MySQL
